# 队友修改指南：景点文案与图片

这份指南面向不熟悉项目结构的内容编辑者。日常更新景点时，通常只需要修改一个数据文件，并把图片放进一个固定目录。

## 1. 只需要认识两个位置

- 景点数据：`content/spots.ts`
- 景点图片：`public/spots/`

页面布局、缩放、弹窗与路线逻辑都在其他文件中。只改内容时，不要修改 `app/page.tsx` 或 `app/globals.css`。

## 2. 修改现有景点

打开 `content/spots.ts`，找到对应景点。一个景点的完整写法如下：

```ts
{
  id: 'culture',
  name: '微子文化苑',
  short: '微山岛的人文地标',
  intro: '这里填写完整介绍。',
  tag: '人文',
  time: '建议 60 分钟',
  x: 55,
  y: 52,
  image: '/spots/weizi-culture.webp',
  imageAlt: '微子文化苑入口与园林景观',
},
```

| 字段 | 用途 | 修改要求 |
| --- | --- | --- |
| `id` | 程序识别景点 | 使用小写英文和连字符；已有景点不要随意改 |
| `name` | 景点名称 | 建议不超过 14 个汉字 |
| `short` | 一句话副标题 | 建议 8–18 个汉字 |
| `intro` | 介绍正文 | 建议 80–180 个汉字，写成一段 |
| `tag` | 景点分类 | 如“人文”“自然”“码头” |
| `time` | 建议游览时间 | 保持“建议 XX 分钟”的格式 |
| `x` | 地图横向位置 | 0–100，越大越靠右 |
| `y` | 地图纵向位置 | 0–100，越大越靠下 |
| `image` | 图片路径 | 无图时填写空字符串 `''` |
| `imageAlt` | 图片替代文字 | 描述图片里真实可见的内容 |

## 3. 添加或替换图片

1. 把图片放进 `public/spots/`。
2. 文件名使用小写英文、数字和连字符，例如 `railway-memorial.webp`。
3. 在景点的 `image` 字段中填写 `/spots/文件名`。
4. 在 `imageAlt` 中填写客观的图片描述。

图片建议：

- 首选 WebP，也可使用 JPG 或 PNG。
- 推荐比例 16:9，推荐尺寸 1600 × 900 像素。
- 单张图片尽量控制在 500 KB 以内。
- 不要使用带有版权风险、水印或未经授权的人像图片。

## 4. 新增景点与调整路线

复制一个完整景点对象，修改全部字段，然后放到数组中的合适位置。景点在 `spots` 数组中的先后顺序，同时决定底部快速导航和推荐路线的连接顺序。

如果标记位置不准确，微调 `x` 和 `y`。一次建议只改 1–3 个单位，保存后在本地预览确认。

## 5. 本地检查

在项目目录运行：

```bash
pnpm dev
```

打开终端显示的本地地址，逐个点击景点，检查名称、图片、文案与标记位置。完成后运行：

```bash
pnpm test
pnpm run build:tencent
```

两条命令都成功后再提交代码。

## 6. 推荐协作流程

1. 从最新 `main` 分支创建自己的分支，例如 `content/weizi-culture`。
2. 只提交本次负责的文案与图片。
3. 提交信息示例：`content: update Weizi Culture Park introduction`。
4. 发起合并请求，请另一位队友核对文字、图片授权和地图位置。
5. 合并到 `main` 后，腾讯云 EdgeOne Makers 会自动重新构建（完成 Git 关联后）。

## 7. 常见问题

- 图片不显示：检查文件名大小写与 `image` 路径是否完全一致。
- 页面出现语法错误：检查每个字段结尾是否有英文逗号，字符串是否成对使用单引号。
- 标记偏移：调整 `x` / `y`，不要通过修改 CSS 定位。
- 路线顺序不对：调整景点对象在数组中的顺序。
- 文案遮挡地图：关闭景点卡片或缩放、拖拽地图；不要删除地图交互代码。

## 8. 腾讯云部署配置

项目根目录的 `edgeone.json` 已设置为静态导出：

- 安装命令：`npm install`
- 构建命令：`npm run build:tencent`
- 输出目录：`out`
- Node.js：`22.17.1`

在腾讯云 EdgeOne Makers 中导入 Git 仓库后，确认以上四项与控制台一致。生产分支选择 `main`，以后每次合并到 `main` 都会触发新部署。
